# UGC-03A 사용자 사케 제보 화면

기준 main은 `18331d21695e146578a1b5748d1d6270ff86ab65`다. [PR #19 최종 독립 QA 및 병합](UGC-02C_IMAGE_APPROVAL.md#최종-독립-qa-및-병합)

## 화면 계약

Next.js 16.4.6, React 19.2.8의 App Router, 기존 AuthProvider·Axios Bearer 갱신·TanStack Query·공용 UI 스타일을 사용한다. 사케 목록의 제보 링크와 내 계정의 내 제보 링크가 진입점이다. 로그인 뒤 요청한 계정 하위 경로로 복귀한다. 제보의 쿼리 키와 작성 화면 수명은 현재 회원을 기준으로 분리한다.

- `/account/submissions/new`에서 사케 이름, 기존 양조장 및 해당 양조장의 브랜드를 검색·선택한다. 신규 양조장·브랜드도 제안할 수 있다. 선택 수치와 범위, 용량·변형·출처 등을 입력할 수 있으며 빈 값은 NULL로 유지한다.
- JPEG/PNG는 최대 10 MiB까지 별도로 업로드한다. 첨부에는 권리 근거와 동의가 함께 필요하다. 미리보기는 인증 요청으로 Blob을 받고 화면 종료 시 주소를 해제한다. 과거 첨부는 요청할 때만 읽는다.
- `/account/submissions`와 `/account/submissions/{id}`에서 상태·현재 데이터·과거 리비전 및 처리 사유를 볼 수 있다. 보완 요청 상태에서 최신 리비전을 기본값으로 제출한다. 취소는 확인을 요구한다. 다른 창에서 상태를 바꾼 경우 409 수신 뒤 최신 상태를 읽는다. 승인 중에는 해당 제보를 변경하거나 취소할 수 없으며 승인된 공개 상품은 상세 링크로 이동한다.
- 새 제보는 화면이 열려 있는 동안 같은 요청 본문에 같은 UUID를 재사용한다. 같은 파일을 업로드하다 연결을 잃은 경우 파일 선택을 유지하고 같은 UUID로 다시 시도한다. 작성 내용과 키는 현재 화면의 메모리에 유지된다. 브라우저 새로고침 이후 초안 복원은 후속 범위다.

## 읽기 API 및 UX 부채

사용자 목록 행과 상세 `submission`의 `approvalInProgress`는 V14 `active_submission`으로 계산한다. PENDING·PROCESSING·RETRYABLE_FAILURE 작업만 활성이다. 제보 자체의 `status`는 기존 계약을 유지한다. `nameJa`, `nameKo`는 현재 리비전 표시용이며 `sakeNo`는 소유자 제보의 실제 APPROVED 승인 원장 FK에서 읽는다. 작업 ID·실패 코드·권리 판단·멱등 원장·객체 키와 임대는 사용자 응답에서 선택하지 않는다.

관리자 목록·상세의 `approvalJob`에는 최신 작업 ID, 상태, 활성 여부, 시도 횟수, 실패 코드만 담긴다. 목록에서는 한 SQL의 조인과 V14 `(submission_id,id)`의 최신 행 탐색을 사용한다. 기존 목록 필터·정렬·페이징과 작업 상세 경로를 유지한다.

Worker 비활성 시 관리자 retry는 현재 권한 검증 뒤 503이다. 조회·동일 요청 재생·중단은 그대로 가능하다. READY 업로드 재생은 활성 회원·소유자·키·MIME과 SHA-256이 일치할 때 이미지 permit 없이 같은 영수증을 반환한다. 다른 입력에 같은 키를 쓰면 409다. 신규 업로드의 쿼터와 공유 슬롯의 계약은 그대로다.

## 검증 및 UGC-03B 인수인계

격리 MySQL HTTP 테스트는 사용자 상태와 정보 비공개, 관리자 최신 작업, 실제 승인 상품 링크, Worker 비활성 retry, permit 경합의 READY 재생을 검증한다. Chromium은 로그인 복귀, 실제 Fake Storage 기반 비공개 이미지 첨부와 미리보기, 응답 유실 후 같은 제보 재생, 리비전 보완·취소, 승인 상태 UI를 검증한다. 활성 상태 UI만 응답을 대체하며 서버 계약은 별도 HTTP 테스트가 확인한다. 최신 실행은 PR 검사를 참고한다.

UGC-03B에서 관리자 목록의 요약과 기존 작업 상세를 이용해 검수 큐, 리비전 비교, 권리 판단과 작업 관리를 연결한다. 실제 R2와 운영 적용은 검증 범위 밖이다.
